# Anleitung

## Spiele
Die Spiele sollten als JSON unter [Spiele](Spiele) hochgeladen werden. Wenn eine neue Datei (z.B. für eine neue Mannschaft) angelegt wird, muss diese unter [File_Overview](Spiele/File_Overview.json) eingetragen werden.

## Logos
Teamlogos werden nach [Logos](Logos) hochgeladen. Nach Möglichkeit sind PNGs mit transparentem Hintergrund zu nutzen. Der Dateiname sollte dem Teamnamen aus den JSONs entsprechen.

## Sponsoren
Sponsorenlogos werden nach [/Sponsoren](Sponsoren) geladen und in [sponsoren_overview.json](Sponsoren/sponsoren_overview.json) konfiguriert.

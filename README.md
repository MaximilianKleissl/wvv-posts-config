# Anleitung

# Spiele
Die Spiele sollten als JSON unter `Spiele` hochgeladen werden. Wenn eine neue Datei (z.B. für eine neue Mannschaft) angelegt wird, muss diese unter `File_Overview` eingetragen werden.

# Logos
Teamlogos werden nach `Logos` hochgeladen. Nach Möglichkeit sind PNGs mit transparentem Hintergrund zu nutzen. Der Dateiname sollte dem Teamnamen aus den JSONs entsprechen.
